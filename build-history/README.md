# AI build history

FINN was built in four Claude Code sessions that ran locally on my machine, so they have no share links. These files are readable copies of the full conversations.

| File | Covers |
|---|---|
| [01-initial-analysis-and-setup.md](01-initial-analysis-and-setup.md) | Reading the ENAM brief, choosing the plan, repo and keys |
| [02-blocks-1-to-6.md](02-blocks-1-to-6.md) | Prices, alerts, filings pipeline, ranking, results card, bio card, promise tracker, first frontend, deploy |
| [03-blocks-7-to-10.md](03-blocks-7-to-10.md) | Results-card verification, management card, research for any ticker, Brief me, code freeze |
| [04-blocks-10b-to-12-and-refinements.md](04-blocks-10b-to-12-and-refinements.md) | Review against the brief, XBRL statements, research views, narrative vs numbers, Pulse, Copilot, push refinements, deliverables |

What is in them: what I asked, what Claude answered, and every tool it used (one line each). Left out: raw tool output, hidden reasoning and system messages. Removed: API keys, email addresses and my local file path.

How I worked: one block at a time. Claude wrote a short brief with the decisions as tables; I answered; it built, tested and recorded each decision in `DECISIONS.md`. I challenged and overruled it in places (see the "decision" entries), and it challenged me.
